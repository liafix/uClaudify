# PASS 0 Non-goals

FinBridge Cloud does not attempt to implement or claim:

- a production banking platform,
- access to any real bank/customer dataset,
- uCloudify's internal architecture or client work,
- authentication or multi-tenant user management,
- a live LLM dependency for the golden path,
- arbitrary SQL/shell AI tools,
- Kubernetes, Kafka, Databricks, Snowflake, C# or Scala in the MVP,
- cloud deployment as proof of correctness.

These exclusions are deliberate candidate-demo scope controls.
